# gconf context

Это стартовый набор материалов для участников gконф: как не потеряться в AI-инструментах, безопасно работать с агентами, проходить практические задания и собирать свой рабочий контекст.

Репозиторий можно скачать, открыть в Codex, Claude Code, Cursor или другом кодинг-агенте и использовать как рабочую папку. Внутри лежат гайды, микроквесты, готовые команды для агента и шаблоны файлов.

## Быстрый старт

Если вы здесь впервые:

1. Прочитайте `docs/ai-tools-map.md` - там простая карта: чем чат отличается от агента и что вообще выбрать.
2. Прочитайте `docs/safety-and-secrets.md` - как работать с файлами, токенами, `.env` и GitHub без лишнего риска.
3. Выберите один маршрут ниже и откройте соответствующие файлы.

Если вы открыли репозиторий в агенте, можно написать:

```text
изучи README.md и предложи мне маршрут на 3 шага. я новичок в AI-агентах, хочу начать безопасно и без перегруза.
```

## Что внутри

### `docs/`

База, которую стоит прочитать перед практикой:

- FAQ;
- карта AI-инструментов;
- безопасность, секреты и доступы;
- что делать, если страшно, непонятно или человек застрял.

### `guides/`

Большие инструкции:

- Claude Code как персональная рабочая среда;
- OpenClaw;
- GitHub;
- Cursor;
- Second Brain.

### `microquests/`

Практические задания. Они короткие, прикладные и проверяемые:

- подключить Telegram MCP;
- сделать простую HTML-игру;
- собрать свой MCP;
- выложить проект на GitHub;
- задеплоить на Railway;
- собрать Telegram-бота;
- попробовать несколько агентов на одну задачу.

### `skills/`

Готовые markdown-команды для агентов. Их можно скопировать в папку команд своего инструмента или просто вставить в чат с агентом.

- `daily.md` - собрать фокус дня;
- `coach.md` - короткий коучинговый разговор;
- `content.md` - пост или анонс из сырого материала;
- `tasks.md` - вытащить задачи из текста;
- `meeting.md` - сделать summary созвона;
- `research.md` - провести ресёрч;
- `remind.md` - сделать напоминания о событии;
- `describe-video.md` - собрать описание видео из транскрипта.

### `templates/`

Заготовки файлов:

- `openclaw.env.example`;
- starter для `CLAUDE.md`;
- starter для `AGENTS.md`;
- шаблон напоминаний;
- шаблон описания видео;
- шаблон Q&A summary.

### `events/`

Короткие конспекты Q&A: инструменты, безопасность, память, skills, MCP, тестирование, Obsidian.

## Главное правило безопасности

Не кладите в этот репозиторий реальные ключи, токены, `.env`, клиентские данные, личные переписки и приватные ссылки.

Для секретов используйте только локальные `.env` файлы и добавляйте их в `.gitignore`. Для публикации оставляйте только `.env.example`.

Подробнее: `docs/safety-and-secrets.md` и `SECURITY.md`.
