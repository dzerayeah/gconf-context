# gconf participant repo draft

Это черновик структуры будущего репозитория для участников.

Здесь пока не финальные материалы, а ревью-скелет: какие разделы можно собрать из уже существующего контента в `context/`, из каких источников они берутся и что нужно очистить перед публикацией.

## Что внутри

- `docs/` - база для участников: FAQ, карта инструментов, безопасность, что делать если застряли.
- `guides/` - большие гайды, которые уже есть в текущей базе и могут быть адаптированы.
- `microquests/` - практические задания, пересобранные из event descriptions.
- `skills/` - реальные команды/скиллы, которые можно вытащить из существующих гайдов и `.claude/commands`.
- `templates/` - заготовки файлов: `CLAUDE.md`, `AGENTS.md`, `.env.example`, summary templates.
- `events/` - очищенные Q&A-конспекты.

## Правило v0

В эту структуру попадает только то, что уже можно собрать из имеющихся файлов. Не добавляем "что было бы полезно когда-нибудь", пока для этого нет источника в текущей папке.
