# gconf context

Это папка с материалами для участников gconf про AI-агентов, рабочий контекст, GitHub, Railway, skills, tone of voice и безопасный старт.

## Для участника

Вам не нужно читать всё вручную.

Откройте эту папку в агенте и напишите:

```text
расскажи, что есть в этой папке, что где лежит и с чего мне начать.
```

Агент сам посмотрит файлы и объяснит простыми словами.

## Для агента

Сначала расскажи участнику, что есть в папке.

Держи ответ коротким:

- что это за репозиторий;
- какие здесь основные разделы;
- какие 1-2 файла открыть первыми;
- какой один следующий шаг сделать.

Не перегружай участника списками, техническими деталями и длинными маршрутами.

## Что внутри

- `docs/` - база: карта инструментов, безопасность, FAQ, что делать если застряли.
- `guides/` - подробные инструкции по отдельным сценариям.
- `guides/skills.md` - как собирать свои skills для повторяемых задач.
- `skills/` - добавленные внешние skills.
- `templates/` - шаблон файла правил для агента.
- `qa/` - большой справочник вопрос-ответ.
