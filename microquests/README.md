# microquests

Микроквесты - это короткие практические задания. Их смысл не в том, чтобы сразу сделать идеальный продукт, а в том, чтобы руками пройти один навык.

Рекомендуемый порядок:

1. `02-html-game.md` - самый безопасный старт: локальная игра без внешних сервисов.
2. `07-github.md` - сохранить проект и научиться откатываться.
3. `08-railway.md` - выложить простую штуку в интернет.
4. `10-telegram-bot.md` - пройти полный цикл с ботом.
5. `09-second-brain.md` - собрать папку контекста для агента.

Если вы уже уверенно работаете с агентом, можно идти в MCP, Telegram и swarm agents.

Каждый микроквест устроен одинаково:

- цель;
- что понадобится;
- шаги;
- что проверить;
- если сломалось.
