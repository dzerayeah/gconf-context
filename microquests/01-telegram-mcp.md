# 01 - Telegram MCP

Цель: понять, как агент может работать с Telegram через MCP, и сразу задать безопасные правила.

## Что понадобится

- кодинг-агент с поддержкой MCP;
- тестовый Telegram-бот или отдельный тестовый чат;
- понимание, что read-only безопаснее, чем возможность отправлять сообщения.

## Шаги

1. Создайте отдельный тестовый чат или бота. Не начинайте с рабочего чата команды.
2. Подключите Telegram MCP по инструкции вашего инструмента.
3. Сначала включите только чтение, если MCP это поддерживает.
4. Попросите агента прочитать последние сообщения тестового чата и сделать summary.
5. Если нужна отправка, добавьте правило подтверждения.

Правило для агента:

```text
никогда не отправляй сообщения в Telegram без моего явного подтверждения. сначала покажи получателя, текст и причину. отправляй только после моей точной фразы: отправляй.
```

## Что проверить

- агент видит только тот чат, который должен видеть;
- агент не отправляет сообщения без подтверждения;
- в логах и файлах нет Telegram token;
- вы понимаете, как отключить MCP.

## Если сломалось

Отключите MCP, перезапустите агента и вернитесь к read-only сценарию. Не чините отправку сообщений, пока не работает чтение.
