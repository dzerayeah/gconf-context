# 07 - GitHub

Цель: сохранить проект в GitHub и понять, как возвращаться к рабочей версии.

## Что понадобится

- GitHub-аккаунт;
- папка проекта;
- агент;
- файл `.gitignore`.

## Шаги

1. Откройте папку проекта в агенте.
2. Попросите проверить секреты.

```text
проверь папку перед созданием репозитория: нет ли .env, токенов, ключей, приватных данных. если есть - скажи, что убрать или добавить в .gitignore.
```

3. Попросите создать приватный репозиторий.

```text
создай приватный GitHub-репозиторий для этой папки, добавь README.md и .gitignore, сделай первый commit и push.
```

4. Откройте GitHub и убедитесь, что файлы на месте.
5. Внесите маленькое изменение.
6. Сделайте второй commit.

## Что проверить

- репозиторий приватный;
- `.env` не попал в GitHub;
- есть README;
- есть минимум один commit;
- вы видите историю изменений.

## Практика отката

Попросите агента:

```text
покажи историю коммитов и объясни, как откатиться к предыдущей версии. ничего не откатывай, только объясни.
```

Умение откатиться важнее, чем кажется. Агент будет ошибаться, и GitHub позволяет не начинать с нуля.
