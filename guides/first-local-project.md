# Первый локальный проект

Самый безопасный первый проект с агентом - маленькая HTML-игра без внешних сервисов, токенов и деплоя.

## Что понадобится

- агент;
- пустая папка проекта;
- браузер.

## Шаги

1. Создайте папку `html-game`.
2. Откройте её в агенте.
3. Попросите сделать простую игру в одном `index.html`.

Пример:

```text
сделай простую браузерную игру в одном файле index.html. выбери механику сам: угадай число, змейка, memory cards или кликер. сначала составь короткий план, потом реализуй. игра должна открываться двойным кликом по index.html.
```

4. Откройте `index.html` в браузере.
5. Поиграйте 2-3 минуты.
6. Попросите одну маленькую доработку: счёт, таймер, новый уровень, кнопку restart.

## Что проверить

- файл открывается в браузере;
- игра реально интерактивная;
- есть понятное начало и конец;
- после доработки старая механика не сломалась.

## Если сломалось

Попросите агента:

```text
сравни текущую версию с предыдущей идеей. верни минимальную рабочую версию без усложнений.
```

После этого переходите к `07-github.md`, чтобы научиться сохранять рабочие версии.
