# guides

Большие инструкции по рабочим сценариям.

- `agent-style-and-reflection.md` - как настроить стиль общения агента.
- `tone-of-voice-and-coach-prompt.md` - как настроить tone of voice и коуч-сценарий.
- `skills.md` - как делать свои повторяемые команды.
- `cursor-basics.md` - как начать с Cursor.
- `github-basics.md` - как поручать агенту GitHub, commit и push.
- `railway-deploy.md` - как поручать агенту деплой через Railway.
- `second-brain.md` - как хранить контекст в файлах так, чтобы агент мог с ним работать.
