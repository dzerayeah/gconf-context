# guides

Большие инструкции по рабочим сценариям.

- `claude-code-personal-os.md` - как превратить агент в рабочую среду с памятью и командами.
- `first-local-project.md` - первый безопасный локальный проект с агентом.
- `design-from-reference.md` - как объяснять агенту визуальный дизайн через референсы.
- `agent-style-and-reflection.md` - как настроить стиль общения агента.
- `skills.md` - как делать свои повторяемые команды.
- `cursor-basics.md` - как начать с Cursor.
- `github-basics.md` - зачем GitHub и как не потерять работу.
- `railway-deploy.md` - как выложить проект в интернет через Railway.
- `telegram-bot.md` - полный цикл Telegram-бота.
- `telegram-mcp.md` - как безопасно подключать Telegram MCP.
- `custom-mcp.md` - как подходить к своему MCP.
- `openclaw.md` - как подойти к личному ассистенту в Telegram через OpenClaw.
- `second-brain.md` - как хранить контекст в файлах так, чтобы агент мог с ним работать.
- `swarm-agents.md` - как использовать несколько ролей или агентов на одной задаче.
