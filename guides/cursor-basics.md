# Cursor basics

Cursor - это редактор кода с AI-агентом внутри. Он удобен, если вы хотите видеть файлы, проект и изменения в интерфейсе редактора.

## Когда брать Cursor

Cursor хорош, если:

- Codex или Claude Code не ставятся;
- вам комфортнее работать в IDE;
- проект уже похож на кодовый репозиторий;
- нужно вручную смотреть файлы и изменения.

Если вы не кодите руками, Cursor всё равно может быть полезен: агент внутри него может создавать файлы, запускать проект и объяснять, что происходит.

## Первый запуск

1. Создайте отдельную папку проекта.
2. Откройте её в Cursor.
3. Создайте `README.md`.
4. Откройте чат/agent mode.
5. Попросите агента изучить папку.

Пример:

```text
это новая рабочая папка. изучи её, создай короткий README.md и предложи безопасный первый шаг. пока ничего кроме README не создавай.
```

## Как ставить задачи

Лучше не писать "сделай приложение целиком".

Пишите:

```text
сначала составь план первой минимальной версии. цель - чтобы она работала локально. не добавляй базу, авторизацию и деплой, пока я не попрошу.
```

После плана:

```text
реализуй только шаг 1. после этого скажи, как мне проверить результат.
```

## Что проверять

Перед тем как считать задачу готовой:

- проект запускается;
- нет ошибок в консоли;
- все кнопки, которые должны работать, работают;
- секреты не попали в файлы;
- изменения закоммичены в Git.

## Если Cursor сделал слишком сложно

```text
остановись. убери лишнюю сложность. мне нужна минимальная версия: один экран, одна основная функция, локальный запуск.
```

## Если непонятно, что он делает

```text
объясни простыми словами, какие файлы ты изменил, зачем и как мне проверить результат.
```
