# OpenClaw через агента

OpenClaw - это способ собрать личного ассистента, который живёт в Telegram и работает не только пока открыт ваш ноутбук. Это уже продвинутый шаг: нужен сервер, токены, GitHub-репозиторий для памяти и аккуратная настройка.

Если вы только начинаете, сначала откройте `guides/telegram-bot.md`. OpenClaw имеет смысл, когда вы уже понимаете, что такое бот, сервер, `.env` и GitHub.

## Что подготовить руками

1. VPS-сервер и IP-адрес.
2. Telegram-бот через BotFather.
3. Telegram user id.
4. API key модели, которую будет использовать ассистент.
5. Приватный GitHub-репозиторий для памяти бота.
6. SSH-доступ к серверу.

Не отправляйте секреты в чат с агентом. Храните их локально в `.env`.

## `.env`

Создайте локальный файл:

```bash
mkdir -p ~/.openclaw
nano ~/.openclaw/.env
chmod 600 ~/.openclaw/.env
```

Заполните значения вручную:

```env
SERVER_IP=your_server_ip
SSH_USER=root
SSH_KEY_NAME=openclaw_infra
TELEGRAM_USER_ID=your_telegram_user_id
TELEGRAM_BOT_TOKEN=your_telegram_bot_token
ANTHROPIC_API_KEY=your_anthropic_api_key
GEMINI_API_KEY=
MEMORY_REPO_SSH=git@github.com:your_username/your_memory_repo.git
```

## Что можно поручить агенту

Агент может:

- проверить, что `.env` заполнен;
- сгенерировать SSH-ключ;
- показать публичный ключ, который нужно добавить на сервер;
- подключиться к серверу;
- установить зависимости;
- настроить сервис;
- проверить логи;
- помочь с автоперезапуском;
- настроить сохранение памяти в GitHub.

## Текст для агента

```text
помоги мне развернуть OpenClaw максимально автономно.

правила:
1. делай сам всё, что можешь сделать без моих секретов и ручных кликов.
2. спрашивай меня только там, где без меня физически нельзя.
3. один шаг - одна короткая просьба.
4. не проси отправлять секреты в чат.
5. данные бери из ~/.openclaw/.env.
6. если какого-то поля не хватает - спроси только это поле.
7. перед изменениями на сервере объясняй, что собираешься сделать.

старт:
- проверь наличие ~/.openclaw/.env;
- проверь права на файл;
- сгенерируй SSH-ключ, если его нет;
- покажи публичный ключ;
- дождись, пока я добавлю его в панель сервера;
- дальше веди установку до рабочего Telegram-бота.
```

## Что проверить в конце

- бот отвечает в Telegram;
- сервис на сервере в статусе `active/running`;
- после перезапуска сервера бот снова поднимается;
- память пишется в приватный GitHub-репозиторий;
- токены не попали в публичный репозиторий;
- в логах нет секретов.

## Если агент перегружает вас

Напишите:

```text
сделай это сам и попроси меня только там, где без моего клика или ввода реально нельзя.
```

## Если страшно

Это нормальная реакция. OpenClaw затрагивает сервер, токены и Telegram. Начните с тестового бота и отдельного memory-репозитория, где нет личных данных.
