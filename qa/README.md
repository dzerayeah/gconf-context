# qa

Здесь лежит общий Q&A по материалам репозитория.

Главный файл:

- `qa.md` - вопросы и ответы про инструменты, агентов, безопасность, GitHub, Railway, MCP, Telegram, skills, память, тестирование и рабочий процесс.

Этот раздел сделан как справочник. Его можно дать агенту и попросить отвечать на вопросы участника, опираясь на этот файл.

Пример:

```text
прочитай qa/qa.md и ответь на мой вопрос коротко, практично, с конкретным следующим шагом.
```
