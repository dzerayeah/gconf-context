# skills

Здесь лежат markdown-команды для агента. Их можно использовать тремя способами:

1. Скопировать текст файла и вставить в чат.
2. Положить файл в папку команд вашего агента, если инструмент поддерживает slash-команды.
3. Адаптировать под свой workspace.

## Как пользоваться

Откройте нужный файл и напишите агенту:

```text
используй инструкцию из skills/meeting.md для текста ниже.
```

Или:

```text
прочитай skills/daily.md и проведи меня по этому процессу.
```

## Что есть

- `daily.md` - фокус дня;
- `coach.md` - короткий коучинговый разговор;
- `content.md` - пост или анонс из сырого материала;
- `tasks.md` - задачи из текста;
- `meeting.md` - summary созвона;
- `research.md` - ресёрч;
- `remind.md` - напоминания о событии;
- `describe-video.md` - описание видео из транскрипта.

## Правило

Скилл должен решать одну повторяемую задачу. Если инструкция пытается делать всё сразу, разбейте её на несколько файлов.
