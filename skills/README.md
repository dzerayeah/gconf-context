# skills

Здесь лежат внешние skills, которые можно дать агенту как готовые инструкции.

Сейчас добавлен:

- `frontend-design/SKILL.md` - skill от Anthropic для создания выразительных frontend-интерфейсов без generic AI aesthetics.

Источник:

- Smithery: https://smithery.ai/skills/anthropics/frontend-design
- GitHub: https://github.com/anthropics/claude-code/tree/main/plugins/frontend-design

Как использовать:

```text
прочитай skills/frontend-design/SKILL.md и используй его как инструкцию, когда делаешь frontend: страницу, компонент, приложение или интерфейс.
```
