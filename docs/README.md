# docs

Базовые материалы, с которых лучше начинать.

- `ai-tools-map.md` - карта инструментов: чат, агент, Codex, Claude Code, Cursor, Cowork.
- `faq.md` - короткие ответы на частые вопросы.
- `safety-and-secrets.md` - как работать с файлами, ключами, `.env`, GitHub и MCP.
- `when-stuck.md` - что делать, если страшно, непонятно или всё сломалось.

Если не знаете, что открыть первым, начните с `ai-tools-map.md`, потом перейдите в `safety-and-secrets.md`.
