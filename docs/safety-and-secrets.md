# Safety and secrets

## Что собираем

Гайд для безопасной работы с агентом:

- отдельная рабочая папка;
- что означает доступ к файлам;
- default/full/custom permissions;
- `.env`, токены, ключи, пароли;
- GitHub и `.gitignore`;
- prompt injection и сторонние MCP/skills;
- Telegram/OpenClaw: отдельные боты, allow-list, явное подтверждение перед отправкой.
