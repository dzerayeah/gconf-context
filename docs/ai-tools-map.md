# AI tools map

Самая частая путаница: ChatGPT, Claude, Codex, Claude Code, Cursor, Cowork, Gemini, Nevel - это не одно и то же. Ниже простая карта, чтобы не пытаться поставить всё сразу.

## Два типа инструментов

### 1. Чаты

Примеры: ChatGPT в браузере, Claude Chat, Gemini, Nevel, Perplexity.

Чат умеет:

- отвечать текстом;
- помогать думать;
- разгонять идею;
- объяснять непонятное;
- анализировать файлы, если вы их загрузили в чат.

Чат обычно не умеет сам работать с вашим компьютером. Если он пишет "открой терминал", "создай файл", "скопируй команду" - это нормально: у него нет рук в вашей системе.

Когда использовать чат:

- вы ещё не знаете, что именно хотите сделать;
- нужно обсудить идею с телефона;
- нужно попросить объяснить ошибку простыми словами;
- нужно сравнить варианты;
- нужно подготовить задачу для агента.

### 2. Агенты

Примеры: Codex, Claude Code, Cursor, Cowork.

Агент умеет:

- читать файлы в рабочей папке;
- создавать и редактировать файлы;
- запускать команды;
- работать с Git;
- запускать тесты;
- подключаться к внешним сервисам через MCP или плагины;
- собирать приложения, сайты, ботов и автоматизации.

Когда использовать агента:

- нужно реально что-то сделать в файлах;
- нужно собрать проект;
- нужно исправить ошибку;
- нужно разложить задачу на шаги и довести до результата;
- нужно работать с репозиторием.

## Что выбрать

Для старта достаточно:

- один чат;
- один агент.

Не надо ставить всё сразу. Если у вас уже есть платный ChatGPT - начните с Codex. Если уже есть Claude - начните с Claude Code или Cowork. Если вы уже сидите в Cursor и он работает - оставайтесь в Cursor.

## Как думать про основные инструменты

| Инструмент | Что это | Когда брать |
|---|---|---|
| ChatGPT | чат | идеи, объяснения, бытовые задачи, анализ текстов |
| Claude Chat | чат | тексты, размышления, документы, объяснения |
| Codex | кодинг-агент | проекты, файлы, GitHub, приложения, боты |
| Claude Code | кодинг-агент | проекты, файлы, рабочая среда, автоматизация задач |
| Cowork | агент-помощник Anthropic | контент, файлы, интеграции, задачи не только про код |
| Cursor | редактор с агентом | код, веб-приложения, работа в IDE |
| Nevel | чат/обёртка над моделями | когда нужен доступ к разным моделям в одном месте |

Названия и функции быстро меняются. Важнее не выучить все продукты, а понять принцип: чат помогает думать, агент помогает делать.

## Зачем иногда думать в чате, а делать в агенте

Часто мы начинаем с тумана: "хочу что-то с Telegram", "хочу свой сайт", "хочу навести порядок в документах". В этот момент удобнее пойти в чат и попросить:

```text
помоги мне понять, что я вообще хочу сделать. задавай вопросы, пока задача не станет конкретной.
```

Когда стало понятно, что именно делать, переносим задачу в агента:

```text
вот задача. сначала составь план, задай вопросы, если чего-то не хватает, и только потом предлагай реализацию.
```

Это не правило. Если задача понятная, можно сразу идти в агента.

## Минимальная рабочая связка

Хороший стартовый набор:

- чат для размышлений;
- агент для работы с файлами;
- отдельная рабочая папка.

Сначала освойте эту связку. MCP, OpenClaw, базы, Railway и автоматизации можно добавлять позже.
