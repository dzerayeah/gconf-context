# templates

Заготовки файлов, которые можно скопировать в свой проект или workspace.

Как пользоваться:

1. Выберите нужный шаблон.
2. Скопируйте файл в свой проект.
3. Замените placeholders на свои данные.
4. Попросите агента прочитать шаблон и адаптировать под вашу задачу.

Что есть:

- `openclaw.env.example` - пример `.env` для OpenClaw;
- `claude-md-starter.md` - стартовый `CLAUDE.md`;
- `agents-md-starter.md` - стартовый `AGENTS.md`;
- `reminder-template.md` - 4 напоминания о событии;
- `event-description-template.md` - описание видео/созвона;
- `qa-summary-template.md` - summary Q&A.
