# templates

Здесь лежит стартовый шаблон файла правил для агента.

## Что делает шаблон

Шаблон помогает объяснить агенту:

- что это за папка;
- как с вами общаться;
- что можно и нельзя делать с файлами;
- где лежат заметки, решения и важные материалы;
- как сохранять рабочие версии, чтобы ничего не потерялось.

Это не техническая настройка и не код. Это короткая памятка для агента, чтобы он быстрее понимал ваш проект и не начинал каждый разговор с нуля.

## Почему с него удобно начинать

Когда в папке есть такой файл, агент сразу видит базовый контекст:

- зачем существует проект;
- какой стиль общения вам подходит;
- какие границы безопасности важны;
- куда записывать важные решения;
- как сохранять результат.

Это снижает хаос и помогает новичку не держать все правила в голове.

## Как называется файл

Содержимое шаблона общее, но имя файла зависит от агента:

- в Codex это обычно `AGENTS.md`;
- в Claude Code это обычно `CLAUDE.md`;
- в других инструментах это может называться rules, instructions, project context или иначе.

Если не уверены, спросите самого агента:

```text
как в этом инструменте называется файл с правилами проекта и куда его положить?
```

## Как пользоваться

Попросите агента скопировать `agent-context-starter.md` отсюда в ваш проект, переименовать под ваш инструмент и адаптировать под вашу задачу.

Например:

```text
скопируй `templates/agent-context-starter.md` из этого репозитория в мой проект, назови файл так, как нужно для моего агента, и помоги заполнить его под мою папку.
```

Что есть:

- `agent-context-starter.md` - общий стартовый шаблон правил для агента.
