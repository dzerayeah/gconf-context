# Event description template

Шаблон для описания видео, созвона или разбора.

```markdown
## [Название]

### О чём

[1-3 предложения: что это за видео/созвон, кому полезно, что человек поймёт или сможет сделать после]

### Ключевые моменты

- [мысль 1]
- [мысль 2]
- [мысль 3]

### Что можно сделать дальше

- [конкретное действие]
- [файл или микроквест, который стоит открыть]
- [что проверить руками]

### Таймкоды

00:00 - [тема]
05:10 - [тема]
12:30 - [тема]
```

Правила:

- не выдумывать содержание;
- не превращать описание в длинную статью;
- таймкоды добавлять только если они есть;
- писать так, чтобы человек понял, зачем смотреть.
