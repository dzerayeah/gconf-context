# Reminder template

Используйте для событий, созвонов, практик и вебинаров.

```markdown
# Напоминания: [название события]

Дата: [дата]
Время: [время и часовой пояс]
Ссылка: [ссылка, если есть]
Запись: [будет / не будет / неизвестно]

---

## За день

[дата], [время] - [название события]

Завтра встречаемся на [название]. Будет [что будет происходить простыми словами].

Если хотите подготовиться, [что сделать заранее].

[Запись будет / записи не будет / запись уточним].

---

## Утром

Сегодня в [время] - [название события]

Подготовьте [компьютер / наушники / файл / вопрос], если это нужно. Если не успеваете быть онлайн, [что делать с записью].

---

## За час

Через час, в [время] - [название события]

Ссылка: [ссылка]

Проверьте звук, интернет и [что ещё нужно].

---

## За 3 минуты

Через 3 минуты начинаем [название события]

Ссылка: [ссылка]

Открывайте, устраивайтесь, можно сделать вдох-выдох.
```
