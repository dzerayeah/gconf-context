# CLAUDE.md starter

Скопируйте этот шаблон в `CLAUDE.md` в корне своего workspace и заполните.

```markdown
# Рабочий контекст

## Кто я

[имя, роль, чем занимаюсь, какие проекты сейчас важны]

## Как со мной общаться

- отвечай на русском;
- пиши коротко и по делу;
- если задача неясна, сначала задай вопросы;
- не перегружай меня теорией, давай следующий конкретный шаг;
- если видишь риск, говори прямо;
- не используй сложные термины без объяснения.

## Как работать с файлами

- сначала изучи структуру проекта;
- перед большими изменениями предложи план;
- не редактируй файлы за пределами этой папки без разрешения;
- не удаляй файлы без явного подтверждения;
- не трогай `.env` и секреты;
- перед GitHub push проверяй, что нет токенов и приватных данных.

## Где что лежит

- `notes/` - заметки;
- `daily-logs/` - логи дней;
- `meetings/` - созвоны;
- `projects/` - проекты;
- `skills/` - команды;
- `decisions.md` - важные решения.

## Память

Если в ходе работы появляется важный факт, решение или правило, предложи записать его в подходящий файл. Не рассчитывай, что следующий чат будет помнить текущий разговор.

## Git

- перед commit показывай summary изменений;
- не коммить `.env`;
- не пушь без моего подтверждения;
- если в репозитории есть чужие изменения, не перетирай их.
```
