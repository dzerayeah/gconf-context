# Стартовый файл правил для агента

Скопируйте этот шаблон в корень своей рабочей папки и переименуйте под инструмент, которым пользуетесь.

Название файла может быть разным:

- для Codex это обычно `AGENTS.md`;
- для Claude Code это обычно `CLAUDE.md`;
- в других агентах это может называться rules, instructions, project context или иначе.

Если не уверены, спросите агента:

```text
как в этом инструменте называется файл с правилами проекта и куда его положить?
```

Сам шаблон:

```markdown
# Рабочий контекст

## Что это за папка

[коротко опишите проект: что здесь лежит, зачем это нужно, какой результат хотите получить]

## Как со мной общаться

- отвечай на русском;
- пиши простыми словами;
- не перегружай меня теорией;
- если задача большая, сначала предложи короткий план;
- если я путаюсь, дай один следующий шаг;
- если видишь риск, скажи прямо и спокойно.

## Как работать с файлами

- работай только внутри этой папки проекта;
- не удаляй файлы без моего явного подтверждения;
- не меняй файлы за пределами этой папки без отдельного разрешения;
- если нужно сохранить важное правило, решение или факт, предложи записать это в файл.

## Что важно помнить

- [важные факты о проекте]
- [что уже решено]
- [какие материалы нельзя трогать]
- [какой формат результата мне удобен]

## Где что лежит

- `README.md` - описание проекта;
- `notes/` - заметки;
- `journal/` - дневник или итоги;
- `projects/` - отдельные направления;
- `decisions.md` - важные решения.

## GitHub

- сохраняй рабочие версии в GitHub, чтобы ничего не потерялось;
- перед сохранением коротко объясняй, что изменилось;
- если видишь личные данные или приватные материалы, сначала предупреди меня.
```
